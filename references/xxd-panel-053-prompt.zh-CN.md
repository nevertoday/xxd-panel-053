# XXD Panel 053｜观察式钢笔淡彩手稿生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、比例、姿态、方向、动作、叙事关系、光线、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

不要完整描摹照片。只选取最值得记录的轮廓、动作与关系，把最重要的轮廓或动作变成一个视觉动机，通过重复、变奏、重音、停顿与突然留白组织页面。让纤细钢笔线和少量透明淡彩在接近白色的纸面上保留观察、删减、犹疑和适时停笔的痕迹。

严格遵循这条因果链：锁定身份、比例、姿态、方向与叙事关系 → 保留三个识别线索 → 只选择值得记忆的线 → 把最强轮廓或动作变成一个视觉动机 → 重复、变奏、重音、停顿并停笔 → 仅在识别所需位置加入源图淡彩 → 让近白纸面成为休止 → 让文案成为轻微重音、停顿或回声。

## 硬性视觉要求

- 从剪影、比例、姿态、朝向、动作、结构、关系或场景含义中保留至少三个源图专属线索，同时主动删除次要描述。
- 线条纤细、松动、不均匀，允许断续轮廓、寻找线、重复修正、突然加重、轻微偏差与未完成边缘；一两处自由果断的长线形成重音，但关键比例与方向必须准确。
- 以最重要轮廓或动作为视觉动机，出现有意义的重复与变奏；一个重音之后，其余线条迅速减弱。大片空白是主动休止，不是待填区域。
- 只从源图提取两至四种最具辨识度的颜色，作轻薄、透明、局部点染；允许越线、水痕、颗粒与覆盖不均，环境颜色必须迅速消失。
- 纸色根据源图综合色温与情绪调整为极浅、干净、近白的综合色底，可微暖、微冷或带极轻色相，但不得成为明显彩色背景。
- 双联输出中，“自然衔接”只指固定中线两侧的视觉过渡语言：用源图轮廓方向、动作延伸、色彩回声或留白节奏引导视线跨越接缝。最终画布的结构分割仍必须严格50/50，源照片一侧不得重绘或变形。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。文字只能从主体、动作、环境、情绪、声音、时间、记忆或偶然细节中提炼为一个词、短句、符号或极短标题；沿轮廓、视线、动作方向、未完成边缘或留白进入页面，像轻微重音、停顿或回声。不得形成菜单式信息区。用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标签或伪文字。

## 模式与验收


拒绝：描述性描摹、完整水彩风景、平均分布、填满背景、过度精描、装饰性笔触、粗黑轮廓、矢量线、卡通、3D渲染、菜单排版与商业海报模板。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
